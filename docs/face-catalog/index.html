지금 렌더러(display.cpp)와 다른 점

    
    
      
  • 현재는 SDL로 매끈한 타원을 그립니다. 시안은 같은 도형을 도트 격자로 샘플링하고, 가장자리 도트를 작고 흐리게 찍어 부드럽게 보이게 합니다. C++에서도 도트마다 거리 함수를 계산하는 같은 방식으로 옮길 수 있습니다.
    • 
      
  • 기쁜 눈은 현재 높이만 줄인 납작한 타원(0.07H)입니다. 시안은 ^ ^ 모양 호로 바꿨습니다.
    • 
      
  • 현재는 idle 미소·speaking 입·sad 처진 입을 모두 그립니다. 시안 기본값은 말할 때만 ω 입을 보이고, “입 → 명세대로”로 바꾸면 현재 동작과 같아집니다.
    • 
      
  • 수염, 눈 반짝임 점, 땀방울(unknown), 반짝이(succeeded)는 명세에 없는 장식입니다. 모두 기존 값 조합만으로 그리므로 인터페이스를 바꿀 필요는 없습니다.
    • 
      
  • 확장 후보 3종은 새 activity/emotion 값을 합의해야 쓸 수 있습니다(명세 Open Questions). 지금 보내면 렌더러가 무시하거나 거절합니다.
    • 
      
  • 아래 문구는 실제 패널처럼 글꼴로 그렸습니다. 도트와 글자의 가독성은 LCD 도착 후 실물로 확인해야 합니다.
