# 도트 표정

[표정 일람 페이지](face-catalog/index.html)는 화면 명세의 `activity`·`emotion`·`actionStatus` 조합을 7인치 LCD (C) 1024×600에 맞춘 **도트 표정**으로 미리 그려 보는 페이지입니다. 브라우저에서 파일을 바로 열면 됩니다. 같은 표정이 [display.cpp](../src/display.cpp)의 화면 렌더러에 들어가 있어 모의 실행(시뮬레이터) 창과 Jetson 화면에 그대로 나옵니다. 이 문서는 그리는 방식, 매개변수, 설정값을 정리합니다. 실물 LCD에서의 가독성·인상은 아직 확인하지 않았습니다.

## 페이지에서 볼 수 있는 것

| 묶음 | 표정 | 보내는 값 |
| --- | --- | --- |
| 활동 상태 | 대기, 듣는 중, 생각 중, 말하는 중, 대답 기다림 | `activity` 5종, `emotion: neutral` |
| 감정 | 기쁨, 슬픔, 기쁘게 말하기, 위로하며 말하기 | `emotion: happy·sad`, `activity: idle·speaking` |
| 업무 결과 | 성공, 실패, 결과 미확인 | `actionStatus` 3종 + 명세 권장 감정 |
| 확장 감정 | 쓰다듬기, 졸림, 놀람 | `emotion: petted·sleepy·surprised` (하드웨어 확장 값) |

페이지 설정으로 도트 크기(6·8·10·12px), 도트 모양, 수염, 입(없음·말할 때만·명세대로), 번짐, 움직임을 바꿔 볼 수 있습니다. 선택한 설정은 브라우저에만 저장됩니다. 렌더러 기본값은 페이지 기본값(8px, 동그라미, 수염 보이기, 말할 때만 입, 번짐 켜기)과 같습니다.

## 그리는 방식

기존 렌더러처럼 도형을 픽셀로 바로 그리지 않고, 화면을 도트 격자로 나눈 뒤 **도트마다 도형까지의 거리**로 밝기를 정합니다.

1. **격자.** 1024×600을 `dot` px 칸으로 나눕니다. 기본 8px이면 128×75칸이고, 남는 세로 픽셀은 위아래로 나눠 가운데 맞춥니다.
2. **도형 = 거리 함수.** 눈·수염·입·장식은 모두 화면 좌표(px)의 부호 있는 거리 함수(SDF)입니다. 안쪽은 음수, 바깥은 양수입니다.
   - 눈: 둥근 사각형(`sdBox`, 모서리 반경 = min(hw, hh))
   - 기쁜 눈 `^`, 입 `ω`·`∩`: 각도를 제한한 원호(`sdArc`)
   - 수염·Z: 선분(`sdSeg`) − 두께
   - 슬픈 눈: 눈 SDF와 비스듬한 반평면의 교집합 `max(a, b)`
   - 눈 반짝임: 원을 빼는 차집합 `max(a, -circle)`
3. **덮임 → 밝기.** 도트 중심에서 `c = clamp(0.5 − d / (dot × 1.35), 0, 1)` 을 구합니다. 1.35가 가장자리 부드러움이며, 레이어 투명도(수염 0.55 등)를 곱합니다. 겹치면 가장 밝은 레이어의 색을 씁니다.
4. **도트 찍기.** 밝기를 8단계로 나눠 같은 (색, 단계)끼리 한 번에 그립니다. 단계가 낮을수록 도트를 **작고 흐리게**(반지름 `0.44 × dot × (0.45 + 0.55f)`, 불투명도 `0.3 + 0.7f`) 찍어 계단 없이 부드럽게 보입니다.
5. **바탕·번짐.** 꺼진 도트를 옅게 깔고(`rgba(60,92,112,.18)`), 켜진 도트 층을 흐리게 한 장 더 겹쳐 LCD 번짐을 흉내 냅니다. 렌더러는 켜진 도트를 가로세로 절반 해상도 텍스처에 모아 선형 보간으로 늘려 겹칩니다(불투명도 140/255).
6. **문구.** 아래 문구(듣고 있어요 등)는 도트가 아니라 기존처럼 TTF 글꼴 36px로 그립니다. 8px 도트로는 한글 획을 표현할 수 없기 때문입니다.

계산량은 레이어의 경계 상자 안 도트만 검사하므로 128×75 기준 프레임당 수천~수만 번의 거리 계산입니다. 도트는 64px 흰 원 텍스처 하나를 색·투명도만 바꿔 찍고, 꺼진 도트 바탕은 처음 한 번만 그려 둡니다. Jetson CPU에서 30fps에 충분할 것으로 예상하지만 측정하지 않았습니다.

## 표정 매개변수

좌표는 1024×600 기준 px입니다. 기본 눈은 지금 렌더러와 같은 위치·크기입니다.

| 항목 | 값 |
| --- | --- |
| 눈 중심 | (348, 240), (676, 240) — 가로 0.34·0.66, 세로 0.40 |
| 눈 반폭·반높이 | 51 × 72 (0.05W × 0.12H) |
| 색 | 민트 (112,238,215), 분홍 (241,142,152), 노랑 (247,199,106), 반짝이 (232,246,250), 배경 (10,19,29) |
| 깜박임 | 5.1초 주기, 0.2초 동안 `|cos|` 곡선으로 감았다 뜸 (슬픔은 0.3초) |
| 수염 | 좌우 3가닥, 안쪽 끝 x = 512 ± 252, 바깥 끝 x = 512 ± 432, y ≈ 388 ± 24, 두께 6.4 |
| 입 ω | 반지름 15 원호 두 개, 중심 (497, 394)·(527, 394) |

| 상태 | 시안 동작 | 지금 렌더러 |
| --- | --- | --- |
| `idle` | 숨쉬기 ±3px, 가끔 시선 ±26px | 깜박임만 |
| `listening` | 눈 1.15배(폭 1.08배), 반짝임, 수염 위로 12px | 눈 높이 1.15배 |
| `processing` | 눈 높이 0.6배, 좌우 ±46px, 수염 떨림 | 높이 0.6배, 좌우 ±18px |
| `speaking` | 눈이 통통 튐, ω 아래로 입이 열렸다 닫힘 | 입 타원 높이 변화 |
| `awaiting_answer` | 오른쪽 눈 18px 위, 시선 위로 | 오른쪽 눈 0.37H |
| `happy`·`succeeded` | `^` 원호 눈(반지름 56, 두께 22)이 튐 | 눈 높이 0.07H |
| `sad`·`failed` | 바깥쪽이 처진 눈, 아래쪽 반짝임, 수염 24px 처짐 | 분홍 + 처진 입 |
| `unknown` | 노란 눈이 위를 보고 땀방울 | 노랑 + 문구 |
| `succeeded` 장식 | 반짝이 3개가 번갈아 깜박임 | 없음 |

## 렌더러 설정

`config/*.json`의 `display.face`에서 바꿉니다. 빠진 값은 기본값을 씁니다.

```json
"face": {"dotSize": 8, "whiskers": true, "mouth": "speaking", "glow": true}
```

| 키 | 기본값 | 허용 값 | 효과 |
| --- | --- | --- | --- |
| `dotSize` | 8 | 4–16 (px) | 도트 간격. 8이면 128×75 |
| `whiskers` | `true` | `true`·`false` | 좌우 수염 3가닥 |
| `mouth` | `"speaking"` | `"none"`·`"speaking"`·`"always"` | 말할 때만 ω 입 / 입 없음 / 대기 중 ω·슬플 때 ∩까지 표시 |
| `glow` | `true` | `true`·`false` | 도트 번짐 |

텍스트 화면(`displayMode: "text"`)은 도트를 쓰지 않고 기존 글꼴 렌더링을 그대로 씁니다.

## 표정 규칙

- 인터페이스는 그대로입니다. 화면은 `activity`·`emotion`·`actionStatus`만 보고 얼굴을 고릅니다. `displayState`는 여전히 쓰지 않습니다.
- 색: `sad` 또는 `failed` → 분홍, 그 외 `unknown` → 노랑, 나머지 → 민트.
- 눈: `happy`·`succeeded`·`petted`이면 `^` 눈(단, `processing` 중에는 기본 눈). `sad`·`failed`는 처진 눈, `surprised`는 동그란 눈, `sleepy`는 가는 눈.
- 입: `mouth` 설정을 따르되 `surprised`의 o 입과 `petted`의 ω 입은 `none`이 아니면 항상 보입니다.
- 장식: `succeeded` 반짝이, `unknown` 땀방울, `petted` 볼 터치, `sleepy` Z.
- `petted`·`sleepy`·`surprised`는 명세의 세 값(neutral·happy·sad)에 더한 **하드웨어 확장 값**입니다. 렌더러는 지원하지만, 출력 모델이 만들 값이 아니라 파이프라인이 상황(터치·장시간 대기·호출어)에 따라 넣는 값입니다. 그 밖의 문자열은 `neutral`처럼 그립니다.

## 시험

```bash
python3 tools/deskpetctl.py face --emotion happy --seconds 3
python3 tools/deskpetctl.py face --activity speaking --emotion sad --status failed --seconds 3
python3 tools/deskpetctl.py face --emotion sleepy --seconds 3
```

`tests/visual.py`는 확장 감정을 포함한 12개 표정과 한글 텍스트 화면을 0°·90° 회전으로 렌더링해 BMP로 저장합니다.
