# 도트 표정

[표정 일람 페이지](face-catalog/index.html)는 화면 명세의 `activity`·`emotion`·`actionStatus` 조합을 7인치 LCD (C) 1024×600에 맞춘 **도트 표정**으로 미리 보는 페이지입니다. 브라우저에서 파일을 바로 열면 됩니다. 같은 자세·변형·도형이 [display.cpp](../src/display.cpp)의 화면 렌더러에 들어가 있어 모의 실행(시뮬레이터) 창과 Jetson 화면에 그대로 나옵니다. 이 문서는 표정을 만드는 방식, 매개변수, 설정값을 정리합니다. 실물 LCD에서의 가독성·인상은 아직 확인하지 않았습니다.

## 설계 원칙

2026-11-02에 다시 설계했습니다. 근거는 Anki Vector·EMO의 눈 표현, 생각할 때 시선을 피하는 행동에 관한 HRI 연구(Andrist 외), 애니메이션 원리를 로봇에 쓴 연구들을 정리한 리뷰입니다.

- **생기 있는 눈, 과하지 않게.** 둥근 눈에 작고 옅은 반사광을 하나만 넣습니다(반지름 0.3r, 흰색 65% + 몸 색 35%). 크거나 두 개면 눈동자·애니 느낌이 나서 피했습니다. 빛은 고정이라 시선을 옮기면 반사광이 살짝 반대로 밀립니다.
- **상태는 시선과 움직임으로.** 멈춘 모양만으로는 상태가 잘 구분되지 않았습니다. 듣는 중에는 사용자를 보고 다가오고, 생각 중에는 위쪽 옆을 보고, 대답을 기다릴 때는 고개를 갸웃합니다.
- **감정은 약하게.** 기쁨은 눈이 조금 납작해지며 올라간 웃는 눈(크게 웃는 순간에만 ^ ^ 아치 눈), 슬픔은 바깥쪽 눈꺼풀이 처진 눈입니다. 색은 슬픔·실패(분홍)와 결과 미확인(노랑)에만 씁니다.
- **같은 상태도 매번 다르게.** 상태마다 작은 변형 동작이 여러 개 있고 무작위로 나옵니다.
- **살아 있는 눈.** 시선이 늘 몇 px씩 미세하게 움직이고, 눈 높이가 ±1.2% 숨 쉬듯 바뀌며, 위가 밝고 아래가 살짝 어두운 음영이 있습니다.

## 움직임 구조

얼굴은 숫자 묶음(**자세**)으로 정해집니다. 매 프레임 목표 자세를 계산하고, 실제 자세는 스프링으로 목표를 따라갑니다.

| 자세 값 | 뜻 |
| --- | --- |
| `LookX`·`LookY` | 시선(두 눈 위치). 입은 0.35배, 수염은 0.25배만 따라가 고개를 돌리는 것처럼 보임 |
| `Scale`·`Tilt`·`Bob` | 얼굴 전체 크기(다가옴), 기울기(갸웃), 위아래 위치 |
| `EyeW`·`EyeH` | 눈 크기 배율 |
| `LidTop`·`LidTopR` | 윗눈꺼풀(양쪽·오른쪽만) |
| `LidSad` | 바깥쪽으로 처진 윗눈꺼풀 |
| `LidHappy` | 웃는 정도. 0~0.8에서 눈 높이 최대 −29%(폭 +6%)로 납작해지고 위로 최대 약 10px 올라감, 0.56~0.64를 넘으면 감은 ^ 아치 눈으로 바뀜 |
| `MouthCat`·`MouthSmile`·`MouthOpen`·`MouthWidth`·`MouthX`·`MouthWave` | ω 입 비중, 입꼬리, 벌림, 폭, 좌우 위치, 물결 |
| `Whisk`·`Blush`·`Zz` | 수염 처짐, 볼 터치, z 표시 |

목표 자세 = 기본값 → 활동(`activity`)의 기본 자세 → 감정의 고정값·더할 값 → 말하기 입 → 미세 시선 → 지금 실행 중인 변형.

- **스프링.** 값마다 강도가 다릅니다(입 700, 시선 220, 기본 150, 기울기 70, 슬픈 눈꺼풀 60 등). 감쇠비 0.78이라 살짝 넘쳤다 돌아옵니다. 상태가 바뀌어도 화면이 뚝 바뀌지 않고 자세가 이어서 움직입니다.
- **변형.** 활동의 변형과 감정의 변형을 한 묶음으로 두고 가중치로 무작위로 고릅니다. 같은 변형은 연달아 나오지 않습니다. 변형이 끝나면 활동마다 정한 간격(예: 대기 1.2~3.6초, 생각 중 0.5~2초)만큼 쉰 뒤 다음 변형을 고릅니다. 변형마다 방향(왼쪽/오른쪽) 같은 무작위 값을 시작할 때 정합니다.
- **깜박임.** 2.2~6초 간격으로 무작위, 22% 확률로 두 번 연속. 상태가 바뀌면 먼저 한 번 깜박입니다(애니메이터가 장면 전환을 숨기는 방식). 졸림은 더 느리게 깜박입니다.
- **말하기 입.** 하드웨어 데몬으로 음성이 재생되는 동안(Jetson의 `speaker.write`)은 **실제 소리 크기**로 입을 엽니다. 받은 PCM을 20ms마다 RMS로 계산해 −48~−14 dBFS를 닫힘~활짝으로 바꾸고(재생 음량 `playbackGain` 적용 전 값), 재생이 시작된 시각부터 같은 시간축에 놓습니다. 소리가 없는 구간은 입이 닫힙니다. 재생 중인 음성이 없으면(음성 없이 말하기 상태만 오거나, 맥 데모처럼 파이프라인이 직접 재생할 때) 입은 닫혀 있습니다. 소리와 안 맞는 무작위 리듬은 말을 안 할 때도 입이 움직여 보여서 뺐습니다. 표정 일람 페이지는 소리가 없으므로 미리보기용으로만 무작위 리듬을 씁니다.
- **미세 시선.** 0.35~1.6초마다 시선을 ±5px(세로 ±3px) 안에서 새로 정합니다. 졸림은 ±1.5px.
- **색.** 감정 색으로 초당 약 6배 빠르기로 서서히 바뀝니다.

## 상태별 표정

| 상태 | 기본 자세 | 무작위 변형 |
| --- | --- | --- |
| 대기 `idle` | 편안한 눈, ω 입 | 두리번, 양옆 살피기, 느긋한 눈감기, 갸웃, 하품, 수염 씰룩, 살짝 다가옴 |
| 듣는 중 `listening` | 얼굴 1.05배로 다가옴, 눈 1.12배, 입 다묾, 수염 위로 | 끄덕, 응응, 갸웃하며 듣기, 집중, 귀 기울이기 |
| 생각 중 `processing` | 왼쪽 위나 오른쪽 위를 봄(들어올 때 무작위), 입이 그쪽으로 모임 | 휙휙, 반대편 보기, 음…, 골똘, 갸우뚱 생각, 아래 훑기 |
| 말하는 중 `speaking` | 사용자를 보고 입이 음절처럼 열림 | 강조, 말하며 시선 돌림, 눈 크게, 끄덕이며 말하기, 갸웃하며 말하기 |
| 대답 기다림 `awaiting_answer` | 얼굴 전체를 약 7.5°(0.13rad) 기울임(좌우 무작위), 작은 미소 | 반대로 갸웃, 빤히, 깜박깜박, 통, 기대 |
| 기쁨 `happy`·`succeeded` | 납작하게 웃는 눈(`LidHappy` 0.5), 미소 | 통통, 좌우 흔들, 방긋(이때만 ^ ^) — 모두 작게 |
| 슬픔 `sad`·`failed` | 처진 눈(`LidSad` 0.8), ∩ 입, 얼굴 14px 내려감, 분홍 | 한숨, 힐끔, 울먹 |
| 결과 미확인 `unknown` | 노랑, 오른쪽 윗눈꺼풀 0.3, 물결 입, 위쪽을 봄 | 어리둥절, 갸웃 |
| 쓰다듬기 `petted` | 납작하게 웃는 눈(`LidHappy` 0.5), 옅은 볼 터치, ω 입 | 비비기, 수염 씰룩, 좋아(이때만 ^ ^) — 모두 작게 |
| 졸림 `sleepy` | 윗눈꺼풀 0.68, 작은 입 | 꾸벅, 하품, Z |
| 놀람 `surprised` | 눈 폭 1.18배, 얼굴 1.05배, o 입 | 깜짝 깜박, 부르르 |

감정이 있는 활동(예: 기쁘게 말하기)은 활동 변형과 감정 변형이 섞여서 나옵니다. 문구는 듣는 중·생각 중·대답 기다림·결과 미확인에만 나옵니다.

## 그리는 방식

화면을 도트 격자로 나눈 뒤 **도트마다 도형까지의 거리**로 밝기를 정합니다.

1. **격자.** 1024×600을 정확히 `dotSize` px 칸으로 나눕니다. 기본 8px이면 128×75칸이고, 남는 픽셀은 가운데 맞춥니다. 칸 간격이 정수 px라서 모든 도트가 같은 모양으로 찍힙니다.
2. **도형 = 거리 함수.** 눈·입·수염·장식은 얼굴 좌표(1024×600 px)의 부호 있는 거리 함수(SDF)입니다.
   - 눈: 둥근 사각형(`sdBox`). 윗눈꺼풀은 반평면(슬플 때 바깥쪽으로 기울어짐). 웃는 눈은 납작하게 줄이고, 크게 웃을 때는 위로 휜 원호(`sdArc`, 두께 24)로 서서히 바뀝니다. 예전처럼 아래를 큰 원으로 깎으면 볼이 부푼 것처럼 보여 바꿨습니다.
   - 입: ω는 원호 두 개(`sdArc`), 미소·∩·물결은 10토막 곡선(`sdTaper`), 벌린 입은 둥근 사각형. `MouthCat`·`MouthOpen`에 따라 서로 투명도를 바꿔 이어집니다.
   - 수염: 살짝 휜 2차 곡선을 6토막의 가늘어지는 선분(반두께 3→1)으로 그리고, 천천히 ±3px 흔들립니다.
3. **얼굴 전체 변환.** 도트 중심을 기울기·크기·위아래 위치의 역변환으로 얼굴 좌표에 옮겨 거리를 잽니다. 중심은 (512, 300)입니다.
4. **덮임 → 밝기.** `c = clamp(0.5 − d × scale / (dot × 1.1), 0, 1)` 에 레이어 투명도(수염 0.55 등)와 음영(눈 아래쪽 최대 −28%)을 곱합니다. 겹치면 가장 밝은 레이어의 색을 씁니다.
5. **도트 찍기.** 모든 도트는 크기와 모양이 같고 밝기만 다릅니다. 도트 그림은 처음에 `dotSize`×`dotSize` px로 한 번 만들고(반지름 `0.42 × dot`, 4×4 슈퍼샘플링) 늘이거나 줄이지 않고 정수 좌표에 찍습니다.
6. **바탕·번짐.** 꺼진 도트를 같은 도트 그림으로 옅게 깔고, 켜진 도트를 절반 해상도 텍스처에 모아 선형 보간으로 늘려 겹칩니다(불투명도 140/255).
7. **문구.** 아래 문구는 도트가 아니라 TTF 글꼴 36px로 그립니다.
8. **화면 맞춤.** 완성된 화면은 창·전체 화면 크기에 맞춰 선형 보간으로 늘리고, 비율이 달라 생기는 여백은 매 프레임 배경색으로 지웁니다(16:10 맥 전체 화면에서 지직거리던 문제). 맥 Retina에서는 고해상도 창을 씁니다.

렌더 주기는 16ms(약 60fps)입니다. `display.displayed`는 새 상태의 첫 프레임에서 보내며, 자세가 다 바뀌는 데는 0.2~0.5초가 더 걸립니다. Jetson CPU에서 60fps에 충분할 것으로 예상하지만 측정하지 않았습니다.

## 기본 매개변수

좌표는 1024×600 기준 px입니다.

| 항목 | 값 |
| --- | --- |
| 눈 중심 | (348, 240), (676, 240) |
| 눈 반폭·반높이 | 64 × 90 (이전 51 × 72에서 키움) |
| 입 중심 | (512, 392), ω 원호 반지름 27, 미소 반폭 52 (`MouthWidth` 1 기준) |
| 수염 | 좌우 3가닥, 안쪽 끝 x = 512 ± 222, 바깥 끝 x = 512 ± 404 |
| 색 | 파랑 (100,206,250), 분홍 (241,142,152), 노랑 (247,199,106), 배경 (10,19,29) |

## 렌더러 설정

`config/*.json`의 `display.face`에서 바꿉니다. 빠진 값은 기본값을 씁니다.

```json
"face": {"dotSize": 8, "whiskers": true, "mouth": "always", "glow": true}
```

| 키 | 기본값 | 허용 값 | 효과 |
| --- | --- | --- | --- |
| `dotSize` | 8 | 4–16 (px) | 도트 간격. 8이면 128×75 |
| `whiskers` | `true` | `true`·`false` | 좌우 수염 3가닥 |
| `mouth` | `"always"` | `"none"`·`"speaking"`·`"always"` | 입 없음 / 말할 때만 입 / 항상 입 |
| `glow` | `true` | `true`·`false` | 도트 번짐 |
| `lipSyncDelayMs` | 0 | 0–500 (ms) | 입 움직임을 소리보다 늦춤. 스피커·USB 지연만큼 실물에서 맞춤 |

텍스트 화면(`displayMode: "text"`)은 도트를 쓰지 않고 기존 글꼴 렌더링을 그대로 씁니다.

## 표정 규칙

- 인터페이스는 그대로입니다. 화면은 `activity`·`emotion`·`actionStatus`만 보고 얼굴을 고릅니다. `displayState`는 쓰지 않습니다.
- 감정: `sad` 또는 `failed` → 슬픔, 그 외 `unknown` → 결과 미확인, `happy` 또는 `succeeded` → 기쁨, `petted`·`sleepy`·`surprised` → 각 확장 감정, 나머지 → 감정 없음.
- `petted`·`sleepy`·`surprised`는 명세의 세 값(neutral·happy·sad)에 더한 **하드웨어 확장 값**입니다. 출력 모델이 만들 값이 아니라 파이프라인이 상황(터치·장시간 대기·호출어)에 따라 넣는 값입니다. 그 밖의 문자열은 `neutral`처럼 그립니다.

## 시험

```bash
python3 tools/deskpetctl.py face --emotion happy --seconds 3
python3 tools/deskpetctl.py face --activity speaking --emotion sad --status failed --seconds 3
python3 tools/deskpetctl.py face --emotion sleepy --seconds 10
```

변형은 무작위라 같은 명령도 매번 조금씩 다르게 움직입니다. `tests/visual.py`는 12개 표정과 한글 텍스트 화면을 0°·90° 회전으로 렌더링해 BMP로 저장합니다.
