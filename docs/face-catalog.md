# 도트 표정 시안

[표정 일람 페이지](face-catalog/index.html)는 화면 명세의 `activity`·`emotion`·`actionStatus` 조합을 7인치 LCD (C) 1024×600에 맞춘 **도트 표정**으로 미리 그려 보는 시안입니다. 브라우저에서 파일을 바로 열면 됩니다. 현재 [display.cpp](../src/display.cpp)는 바꾸지 않았고, 이 문서는 시안을 렌더러로 옮길 때 필요한 기술 내용을 정리합니다. 실물 LCD에서의 가독성·인상은 아직 확인하지 않았습니다.

## 페이지에서 볼 수 있는 것

| 묶음 | 표정 | 보내는 값 |
| --- | --- | --- |
| 활동 상태 | 대기, 듣는 중, 생각 중, 말하는 중, 대답 기다림 | `activity` 5종, `emotion: neutral` |
| 감정 | 기쁨, 슬픔, 기쁘게 말하기, 위로하며 말하기 | `emotion: happy·sad`, `activity: idle·speaking` |
| 업무 결과 | 성공, 실패, 결과 미확인 | `actionStatus` 3종 + 명세 권장 감정 |
| 확장 후보 | 쓰다듬기, 졸림, 놀람 | 새 값 합의 필요. 지금 보내면 렌더러가 무시하거나 거절 |

페이지 설정으로 도트 크기(6·8·10·12px), 도트 모양, 수염, 입(없음·말할 때만·명세대로), 번짐, 움직임을 바꿔 볼 수 있습니다. 선택한 설정은 브라우저에만 저장됩니다.

## 그리는 방식

기존 렌더러처럼 도형을 픽셀로 바로 그리지 않고, 화면을 도트 격자로 나눈 뒤 **도트마다 도형까지의 거리**로 밝기를 정합니다.

1. **격자.** 1024×600을 `dot` px 칸으로 나눕니다. 기본 8px이면 128×75칸이고, 남는 세로 픽셀은 위아래로 나눠 가운데 맞춥니다.
2. **도형 = 거리 함수.** 눈·수염·입·장식은 모두 화면 좌표(px)의 부호 있는 거리 함수(SDF)입니다. 안쪽은 음수, 바깥은 양수입니다.
   - 눈: 둥근 사각형(`sdBox`, 모서리 반경 = min(hw, hh))
   - 기쁜 눈 `^`, 입 `ω`·`∩`: 각도를 제한한 원호(`sdArc`)
   - 수염·Z: 선분(`sdSeg`) − 두께
   - 슬픈 눈: 눈 SDF와 비스듬한 반평면의 교집합 `max(a, b)`
   - 눈 반짝임: 원을 빼는 차집합 `max(a, -circle)`
3. **덮임 → 밝기.** 도트 중심에서 `c = clamp(0.5 − d / (dot × 1.35), 0, 1)` 을 구합니다. 1.35가 가장자리 부드러움이며, 레이어 투명도(수염 0.55 등)를 곱합니다. 겹치면 가장 밝은 레이어의 색을 씁니다.
4. **도트 찍기.** 밝기를 8단계로 나눠 같은 (색, 단계)끼리 한 번에 그립니다. 단계가 낮을수록 도트를 **작고 흐리게**(반지름 `0.44 × dot × (0.45 + 0.55f)`, 불투명도 `0.3 + 0.7f`) 찍어 계단 없이 부드럽게 보입니다.
5. **바탕·번짐.** 꺼진 도트를 옅게 깔고(`rgba(60,92,112,.18)`), 켜진 도트 층을 흐리게 한 장 더 겹쳐 LCD 번짐을 흉내 냅니다.
6. **문구.** 아래 문구(듣고 있어요 등)는 도트가 아니라 기존처럼 TTF 글꼴 36px로 그립니다. 8px 도트로는 한글 획을 표현할 수 없기 때문입니다.

계산량은 레이어의 경계 상자 안 도트만 검사하므로 128×75 기준 프레임당 수천~수만 번의 거리 계산입니다. Jetson CPU에서 30fps에 충분한 수준으로 예상하지만 측정하지 않았습니다.

## 렌더러로 옮길 때

- 인터페이스는 바꿀 필요가 없습니다. 명세 범위의 표정은 모두 기존 `activity`·`emotion`·`actionStatus` 값으로만 결정됩니다.
- `display.cpp`의 `draw()`에서 `ellipse`·입 곡선 대신 위 레이어 목록을 만들고, 격자 루프로 밝기 버퍼를 채운 뒤 도트를 그리면 됩니다. 원은 미리 만든 단계별 도트 텍스처 8장을 `SDL_RenderCopy`로 찍는 방식이 가장 단순합니다.
- 번짐은 켜진 도트를 낮은 해상도 텍스처에 그려 확대해 겹치면 비슷하게 낼 수 있습니다. 성능이 모자라면 끄면 됩니다.
- 입 표시 방식(없음·말할 때만·명세대로)과 수염 여부는 팀이 정한 뒤 설정값으로 둘지 고정할지 결정합니다.
- 확장 후보 3종은 [화면 명세](https://github.com/hansung-capstone-team-8-new-line/knowledge/blob/master/wiki/deskpet-display-interface.md)의 Open Questions대로 새 값 합의가 먼저입니다.
